# Phase 0：真人验证

PRD 第 11、14 节要求在做完整 App 之前，先用纸笔验证核心假设。
本文是执行材料，可直接复制给参与者。

## 要验证什么

**不是**「这个 App 能不能做出来」，而是：

1. 年轻人是否愿意连续记录事实？（PRD 12 风险一：这是最大风险）
2. 他们是否愿意看见自我认知与事实之间的差距？
3. 这种反馈是否真的帮他们更了解自己？

### 判断标准

写在前面，避免事后找理由：

| 信号 | 达标线 |
|---|---|
| 完成率 | 5 人中至少 3 人记满 7 天中的 5 天 |
| 主动性 | 至少 3 人在没被催的情况下自己想起来记 |
| 反馈价值 | 至少 3 人在报告里指出「有一条我没意识到」 |
| 续用意愿 | 至少 3 人愿意继续记第二周 |

**如果没人愿意持续记录，问题不在功能不够，而在假设不成立。**
这种情况下正确的动作是改产品方向，不是加功能。

## 一、初始自我画像问卷（10 题）

参与者在第 1 天填一次，第 8 天再填一次（不给看第一次的答案）。
两次对比本身就是数据。

### 量表题（1-10 分）

1. 你觉得自己是一个自律的人吗？
2. 你觉得自己最近学习或工作的投入度如何？
3. 你觉得自己拖延严重吗？（分数越高表示越拖延）
4. 你觉得自己能坚持长期目标吗？
5. 你觉得自己在多大程度上「说到做到」？

> 第 5 题是新增的。前 4 题偏笼统，第 5 题是唯一能被一周事实直接检验的承诺型陈述。

### 开放题

6. 你觉得自己最近最大的优势是什么？
7. 你觉得自己最近最想改变的问题是什么？
8. 用三个词描述现在的自己。
9. 当你没做成一件事，你通常怎么解释？
10. 过去一个月，有没有一件事你一直想做却一直没开始？是什么？

> 第 9 题采集的是**归因模式**——「我太忙了」「我状态不好」这类解释，
> 正是这个产品要检验的叙事本身。
>
> 第 10 题最重要：它给出一个**可证伪的预测**。
> 如果这件事在接下来 7 天里仍然没有开始，那就是一条谁也没法反驳的事实。

题 1-8 对应现有代码里的 `SELF_PORTRAIT_QUESTIONS`；
9、10 是 Phase 0 新增，验证有效后再考虑加进 App（注意加题需要改 SQLite schema）。

## 二、每日事实题库（10 题）

### 关于「10 题」和「30-60 秒」的冲突

PRD 3.2 要求输入很轻、30-60 秒完成，但第 14 节又要求写 10 道题。
**每天答 10 道题不可能在 60 秒内完成**，硬要求只会导致参与者第三天就放弃——
而那恰好是我们最想避免的失败模式。

处理方式：**10 题是题库，每天只答 4 题**。

- **固定 3 题**（每天都答，保证纵向可比）
- **轮换 1 题**（按星期轮换，7 天覆盖到全部）

### 固定题（每天必答）

1. 今天你实际完成了什么？
2. 今天你原本计划做但没有做的事情是什么？
3. 今天你计划几点开始最重要的那件事？实际几点开始？

> 第 3 题是新增的，而且我认为它是这套题里价值最高的一道。
>
> 用一个月模拟数据跑分析时，最强的信号来自「启动延迟」而非「中途放弃」——
> 但那是从自由文本里勉强读出来的。两个时间点是结构化的、可累加的，
> 一周下来就能看出规律，而「我很自律 / 我很拖延」这类自评看不出任何东西。

### 轮换题（每天一道）

| 星期 | 题目 |
|---|---|
| 一 | 今天有没有一件事证明你在靠近目标？ |
| 二 | 今天有没有一次明显的逃避？你回避了什么？ |
| 三 | 今天有没有一件事比你预想的容易？ |
| 四 | 今天最能代表你真实状态的事实是什么？ |
| 五 | 今天你对自己说过什么解释或借口？ |
| 六 | 如果只能写一句事实，你会写什么？ |
| 日 | 这一周里，有没有你现在才注意到的模式？ |

> 「比预想的容易」是**低估侧**的证据。产品要求指出「可能被低估的地方」，
> 但如果每天只问失败和逃避，采集到的证据会系统性偏向负面，
> 报告也就只能得出负面结论。
>
> 「你对自己说过什么解释或借口」直接采集叙事本身——
> 这是整个产品的名字所指的那个东西，现有题库里反而没有。

## 三、每日提交表（发给参与者）

> 复制以下内容给每位参与者，让他们每天回一条消息即可。
> 不要做成表单或 App——Phase 0 的目的是验证意愿，不是验证工具。

```
【第 N 天 · M月D日】

1. 今天实际完成了：

2. 计划做但没做的：

3. 最重要那件事，计划几点开始 / 实际几点开始：
   计划        实际

4. 【今日轮换题】
```

**给参与者的说明（原话可直接用）：**

> 这不是打卡，也不是让你变得更自律。
> 我在做一个工具，想知道人对自己的判断和实际做的事差多少。
> 你只需要每天花一分钟写几条事实，一周后我会给你一份对照报告。
> 写得难看没关系，写得真实才有用——反正只有我一个人看，
> 而且我不会评价你。

## 四、周反馈报告模板（手工填写）

第 8 天，为每位参与者手写一份。**每条结论必须引用具体日期和原话。**

```
———————————————————————
给 ___ 的第一周对照报告

【你一周前说自己是什么样】
  自律 __/10   投入 __/10   拖延 __/10
  坚持 __/10   说到做到 __/10
  三个词：
  一直想做没开始的事：

【这一周你实际记录了什么】
  记录天数：__ / 7
  计划 vs 实际开始时间：
    平均延迟 __ 分钟，最长 __ 分钟（_月_日）
    有 __ 天准时或提前开始

【事实支持你的地方】
  你说「____」（第 1 天）
  事实：_月_日 ____，_月_日 ____
  →

【事实和你说的不太一样的地方】
  你说「____」
  事实：
  →

【可能被你低估的地方】
  （从「比预想的容易」和完成记录里找）
  →

【目前看不出来的地方】
  （诚实写：哪些方面这周记录太少，无法判断）
  →

【那件一直想做没开始的事】
  一周前你写的是：____
  这周：□ 开始了（_月_日）  □ 仍然没有
  →

【下周可以只观察一件事】
  →
———————————————————————
```

### 写报告时的纪律

对照 PRD 5.3。**这一步最容易出错，也最能决定参与者要不要继续。**

不要写：

> 你其实并不自律。

要写：

> 你给自己的自律评分是 8/10。这一周 5 天里有 4 天，你最重要的那件事
> 都比计划晚了 40 分钟以上开始；但一旦开始，5 次里有 4 次做完了。
> 所以事实更支持「你的稳定性不错，但启动成本偏高」——这和「不自律」
> 是两件事。

三条硬规则：

1. **每条结论都带日期和原话。** 没有具体证据支撑的判断一律删掉。
2. **证据不足就明说证据不足。** 不要为了让报告显得丰满而硬凑结论。
3. **不诊断、不羞辱、不命令。** 你是镜子，不是裁判。

## 五、访谈提纲（第 8 天，每人 15 分钟）

看完报告之后当面或语音问，**不要用问卷**——问卷收不到犹豫和停顿。

1. 这一周记录的时候，最难的是哪一步？
2. 有没有哪天你不想记？那天发生了什么？
3. 报告里有没有哪条让你觉得「确实是这样，但我没意识到」？
4. 有没有哪条你不认可？为什么？
5. 如果这是个 App，你会继续用吗？—— 停顿三秒再问 —— 真的会吗？
6. 你会推荐给朋友吗？推荐给谁？

> 第 5 题的追问很关键。当面问「你会用吗」，几乎所有人都会出于礼貌说会。
> 停顿之后的第二次回答才有参考价值。
>
> 第 4 题比第 3 题更有用：**不认可的地方暴露的是分析逻辑的问题**，
> 而这正是 App 里 SYSTEM_PROMPT 要改的地方。

## 六、时间表

| 天 | 做什么 |
|---|---|
| D0 | 找到 5 人，一对一说明，填初始画像问卷 |
| D1-D7 | 每天收一条记录。**第 3 天有人断了就私聊问原因**——断掉的理由比记录本身更有价值 |
| D8 | 重填画像问卷（不给看第一次的答案）→ 发报告 → 访谈 |
