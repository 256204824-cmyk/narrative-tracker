# 怎么选 AI 服务商

> [English](providers.md)

这个 App 没有服务器。每一份报告都由**你自己选择的 AI 服务**生成，
用**你自己的** Key，从你的设备直接发出。

所以选择权在你手上 —— 而且这件事在这个 App 里比在大多数 App 里更要紧，
因为送出去的东西不一样。

## 挑「免费」的之前，先读这段

请求里装的是你诚实的自我评价，和你每天记下的逃避与失败。
这大概是你能交给第三方的最私密的东西了。

有些免费额度之所以免费，正是因为**你的 prompt 会变成训练数据**，
有时还包含人工审阅。让聊天机器人帮你写封邮件，这个交换是划算的；
换成这里的内容，就未必了。

所以设置页里那个列表**先放手机上真正能用的**，在此前提下按隐私强度而不是免费程度排序。
（本地跑模型是隐私最强的答案，但它需要一台电脑 —— 排在最后是因为这个，不是因为它更差。）

**用哪家就得有哪家的 Key。** 切换预设只会改地址，不会改你的 Key ——
拿着上一家的 Key 请求新服务，只会收到 401。每一行都有「获取 Key」的链接。

## 可选项

核实时间 2026-08-24。各家政策与免费额度都会变，依赖之前请自行复核。

### 从这两家开始：免费、手机可用、不拿你的数据训练

| | 免费额度 | 建议模型 | 数据政策 |
|---|---|---|---|
| **[Groq](https://console.groq.com/keys)** | 有 | `openai/gpt-oss-120b` | 零数据保留；响应返回后 prompt 即从系统中消失，且不用于训练 |
| **[Cerebras](https://cloud.cerebras.ai)** | 每天 100 万 token，无需信用卡 | `gpt-oss-120b` | 输入输出均不保留，也不用于训练或微调 |

注册、把 Key 填进设置，就能用了。两家免费档都给到 65K 上下文，装下一个月的记录绰绰有余。

### 收费，但不拿你的数据训练

| | 数据政策 |
|---|---|
| **OpenAI** | API 数据不用于训练；会短期保留用于滥用监控 |
| **DeepSeek** | 我们没有核实过它的政策，使用前请自行查阅 |

### 免费，但你的记录可能变成训练数据

| | |
|---|---|
| **Google Gemini 免费档** | Google 保留使用免费档输入输出改进产品的权利，包括人工审阅与纳入未来训练集。**付费档**不会。 |
| **OpenRouter 免费模型** | OpenRouter 自身默认不记录，但**免费模型**背后的很多上游服务商要求开启日志和/或训练才能使用 |

它们仍然在列表里，因为藏起来是一种傲慢，也因为对某些人来说这个交换可以接受。
但请让它成为一个**决定**，而不是一次意外 ——
在提交之前，想一想你是否介意一个陌生人读到这些内容。

### 隐私最强，但需要一台电脑

| | |
|---|---|
| **Ollama** | `http://localhost:11434/v1` |
| **LM Studio** | `http://localhost:1234/v1` |

免费、不需要 Key、不需要注册，而且**什么都不出你的局域网** ——
隐私问题不再依赖信任，而是由结构本身决定。

它排在最后只是因为这个 App 的目标用户在手机上，而手机跑不了这些。
如果你手头有一台闲置的电脑，这就是最好的选择。
注意小模型按 JSON schema 输出的能力偏弱；报告生成失败时，
诊断面板会把模型实际返回的内容原样显示出来。

## 关于模型名

模型 ID 会过期。比如 Groq 在 2026 年 6 月弃用了 `llama-3.3-70b-versatile`。
预设会帮你填好 base URL（稳定）和一个建议模型（不稳定）。
模型名不对时服务商会返回 4xx，诊断面板会把对方的报错原文显示出来 ——
去设置里改一下模型名重试即可。

App 刻意**不去拉取**服务商的模型列表。那需要第二个网络请求，
而 [data-flow.md](data-flow.zh-Hans.md) 承诺「在你点击生成报告之前不会有任何流量」。
这个承诺比帮你省一次粘贴更值钱。
