# 隐私策略

> [English](privacy.md)

## 我们的承诺

我们不拥有你的数据。我们不读取你的其他 App。我们不截屏。我们不建立服务器保存你的隐私。你提交什么，App 才分析什么。

## App 保存了什么

| 数据 | 内容 |
|---|---|
| 自我画像 | 你自己填写的评分与短文本，每一版都保留 |
| 事实日志 | 你每天主动输入并保存的记录 |
| 分析报告 | 基于以上两者生成的叙事审计结果 |
| API Key | 你自愿提供的第三方 AI 服务密钥 |
| 偏好设置 | 界面语言、分析范围（档位）、provider 地址与模型名 |

## App 从不采集什么

- 屏幕使用时间
- 任何其他 App 的数据
- 位置信息
- 通讯录
- 健康数据
- 财务信息
- 浏览器历史
- 截屏
- 任何后台行为数据

没有遥测、没有统计 SDK、没有崩溃上报、没有广告 SDK，也没有任何形式的用户标识。
App 不知道你是谁，因为压根没有账号这回事。

## 数据存在哪

**全部留在你的设备上。**

- 事实记录、自我画像、分析报告：App 私有存储里的 SQLite 数据库
- API Key 与偏好设置：系统安全存储 —— iOS Keychain、Android Keystore

**我们不运营任何服务器。** 没有可以被攻破、被调取、被出售的东西，因为我们这边什么都没有。

> **关于 Web 版的说明。** 在浏览器里运行时（仅用于开发），安全存储会退化为
> `localStorage`，那**不是**安全存储。Web 版是开发用的，不是这个 App 的正式形态。
> 不要在上面填真实的 API Key。

## 什么时候有数据离开设备

整个 App 只有一个对外请求：AI 分析调用。它**只在你点击「生成分析报告」时发生** ——
不定时触发、不在后台运行、启动时也不发。

请求发往**你自己配置的地址**（设置 → AI Provider，默认 OpenAI）。
如果你指向本机运行的模型，就完全不出局域网。

请求内容包括：

- 你当前的自我画像：四项评分，以及三段短文本回答
- 最多五个更早的画像版本：评分、日期、描述自己的三个词
- 你所选时间范围内的事实记录 —— 日期、标签、你写的文字
- 由上述内容算出的统计：有记录的天数、各主题的记录条数

仅此而已，全都是你自己输入内容的子集。没有设备标识、没有账号、没有关于你的任何元数据。

API Key 放在同一个请求的 `Authorization` 头里，从你的设备直接发往你选择的服务商。
**它不会经过我们的任何服务器，因为我们没有服务器。**

你选择的服务商会看到这些内容，并按**他们的**隐私政策处理，而不是我们的。
选 provider 就是在选择把这份内容托付给谁 —— 请读一下他们的政策。

## 你可以做什么

你随时可以：

- 查看 App 保存的全部数据
- 导出为 JSON 文件
- 导入之前导出的文件 —— 这会**替换**设备上现有的全部数据
- 永久删除全部本地数据，App 会同时回到初始自我画像流程
- 更换或删除 API Key
- 干脆一次分析都不生成 —— 那样 App 完全不会发起任何网络请求

删除操作不可撤销。如果以后可能还要用，先导出一份备份。
